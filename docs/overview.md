# 总览：模板从源到装机

```text
  贡献者 PR（本仓 YAML）
        │
        ▼
  CI schema 校验 + maintainer 策展 ──► git main / tag（源）
        │
        ▼
  agthelm 官方打包 + 签名 ──────────► *.tar（交付物）
        │
        ├─ 可出网：console / 官网下载 → 验签 → 兼容矩阵 → 安装
        └─ 气隙：摆渡 tar → console 导入 → 同一套验签
```

## 角色

| 角色 | 做什么 |
|------|--------|
| 贡献者 / 集成商 | 在本仓改源、提 PR |
| Maintainer | Review、合入、打源码 tag |
| agthelm 官方 | **唯一**签名发布生产包 |
| 客户管理员 | 只装签名包；断网走离线导入 |
| 一线员工 | 日常 IM / Web 使用已装场景（不进本仓） |

## 复用单元

**场景 × 行业 × 系统栈**（不是泛行业流程）。

模板提供可移植的 prompt / 术语 / 连接器基线 / 评测骨架 / 兼容矩阵。  
逐客户留在现场的：sources 实例、评测实例、部门树 ACL 重绑。

## 禁止误解

1. Clone 本仓 ≠ 可上生产  
2. PR 合入 ≠ 已签名发布  
3. 本仓不会做成「谁发谁装」的商店  

详见产品侧 ADR-004（agthelm 仓）。
